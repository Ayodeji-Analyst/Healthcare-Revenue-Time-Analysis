# 🏥 Healthcare-Revenue-Time-Analysis
This project analyzes a healthcare dataset containing 3,000 patient records collected between 2022 and 2025.  Instead of building a single dashboard, the dataset was explored from two different analytical perspectives:  
- 💰 Revenue Analysis
-  - 📅 Time Analysis

Together, these dashboards provide management with insights into financial performance, patient behavior, and operational trends.


# 🎯 Business Objectives

The project aims to answer questions such as:

- Which diseases generate the highest revenue?
- Which cities contribute the most revenue?
- Which patients generate the highest revenue?
- Which payment methods are used most frequently?
- How does revenue change over time?
- Which months record the highest patient visits?
- Which days experience the highest patient volume?
- How has annual revenue changed from 2022–2025?
